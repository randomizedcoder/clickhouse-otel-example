# Status Update - 2026-03-03

## Summary

Added Nix derivations for external Docker images (OTel Collector, Redpanda, Redpanda Console) to enable MicroVM deployments without requiring external image pulls at runtime.

## Problem

MicroVM tests were failing (0 pods running) because the K8s manifests referenced external Docker images that MicroVM couldn't pull:
- `otel/opentelemetry-collector-contrib:0.96.0`
- `docker.redpanda.com/redpandadata/redpanda:v24.3.8`
- `docker.redpanda.com/redpandadata/console:v2.8.4`
- `curlimages/curl:latest`

## Solution

Used `dockerTools.pullImage` with locked digests for reproducible image pulls, integrated into the Nix container infrastructure.

### Approach by Component

| Component | Strategy | Notes |
|-----------|----------|-------|
| OTel Collector | `dockerTools.pullImage` | Also built OCB (builder tool) from source |
| Redpanda | `dockerTools.pullImage` | C++ Seastar project - impractical to build from source |
| Redpanda Console | `dockerTools.pullImage` | Go + React - could build from source but pulled for simplicity |
| curl init job | Replaced with `clickhouse:latest` | ClickHouse image includes bash + curl |
